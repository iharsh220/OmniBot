How to use your widget URLs

  1. Open Studio, pick a widget and a theme, copy its URL.
  2. OBS / Streamlabs: Sources → + → Browser → paste URL → width 400, height 700 (stats: 800 × 140). The background stays transparent.
  3. Desktop overlay apps (like Transparent-Twitch-Chat-Overlay): use the custom/“chat URL” option and paste the same URL.
  4. Go live. Chat appears automatically within a few seconds of your stream starting.
